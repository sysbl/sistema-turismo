Cómo funciona

Esta página explica el funcionamiento técnico del proyecto y no se enlaza desde la página pública. Para ver el detalle de cada búsqueda en la página principal, agrega ?tecnico=1 a la dirección.

Solo Python da órdenes. Scala y Prolog nunca se hablan entre sí: cada uno recibe un texto, trabaja y devuelve otro texto.

  1. 1

    Python recibe

    Valida tu nombre, tu presupuesto y tu interés, y se los pasa a los otros dos.

    python/main.py
  2. 2

    Scala calcula

    Compara tu monto exacto con el costo de cada destino y devuelve el nivel de presupuesto y los destinos que alcanzan.

    RESULTADO|nivel=medio|…
  3. 3

    Prolog razona

    Recibe tu monto y tu interés, aplica sus reglas sobre hechos para encontrar destinos y, además, sugiere lugares cercanos del mismo departamento.

    centro_historico,valle_sagrado
  4. 4

    Python compara

    Normaliza los dos resultados (sin tildes ni mayúsculas) y revisa si tienen los mismos destinos.

    coinciden: true

Un mismo criterio: Scala y Prolog comparan tu monto exacto con el costo de cada destino. Así, si las dos listas no coinciden, algo está mal en los datos y el sistema lo avisa.
